# 崩坏：星穹铁道（Honkai: Star Rail）抽卡机制事实卡

> 用途：作为建模的「事实来源」。数值基于 GGanalysis（1500 万抽统计）与官方公示综合概率。
> 机制与原神角色池高度相似（50/50 + 大保底），但**无捕获明光**；光锥池为 75/25（非原神 EP 定轨）。

## 卡池覆盖总览

| 卡池 | banner 键 | 机制 | GGanalysis 模型 | 状态 |
|---|---|---|---|---|
| 角色活动跃迁 | `character` | 50/50 + 大保底（无捕获明光）| `up_5star_character` | ✅ 已实现并验证 |
| 光锥活动跃迁 | `weapon` | 75/25 + 大保底必出当期（**非 EP 定轨**）| `up_5star_weapon` | ✅ 已实现并验证 |
| 常驻跃迁（任意5★）| `standard` | 纯保底，无 50/50 | `common_5star` | ✅ 已实现并验证 |
| 新手跃迁 | — | 一次性、折扣 | ❌ GGanalysis 无 | ⬜ 推迟（D23）|
| 4 星跃迁 | — | 独立保底 | ❌ 未建模 | ⬜ 范围外 |

> 所有「已验证」均指适配层输出与 GGanalysis 对应模型逐点一致（误差 < 1e-12）。

### 联动池 / 双限定

星铁存在联动角色池，**无独立概率模型**：机制与角色活动跃迁相同（50/50 + 大保底），UIGF 历史若出现双限定类型，应与角色池共享保底计数（类比原神 301/400 合池，见 `docs/games/genshin.md`）。本项目当前**未实现**星铁 UIGF 历史还原（`history_policy=None`）。

## 角色活动跃迁（Character Event Warp）

| 机制 | 数值 |
|---|---|
| 5★ 基础概率 | 0.6% / 抽 |
| 5★ 软保底起点 | 第 74 抽起线性提升 |
| 5★ 硬保底 | 第 90 抽 100% |
| 50/50 | 出 5★ 时 50% 为当期 UP；歪则下个 5★ 必为 UP（大保底）|
| 捕获明光 | **无** |

### 已实测核对（GGanalysis 0.4.2）

- 1 个 UP 5★ 期望：**≈ 89.55 抽**（软保底略早于原神）
- 任意 5★（常驻池）期望：**≈ 62.30 抽**

## 光锥活动跃迁（Light Cone Event Warp）

| 机制 | 数值 |
|---|---|
| 5★ 基础概率 | 0.8% / 抽 |
| 5★ 软保底起点 | 第 66 抽起 |
| 5★ 硬保底 | 第 80 抽 |
| UP 概率 | 75% 当期 / 25% 常驻；歪则下个 5★ 必为当期 |

> **与原神武器池的区别**：星铁光锥池使用 `up_5star_weapon`（经典 75/25 + 大保底），**没有**原神 5.0 起的「定轨命定值」（Epitomized Path / `up_5star_ep_weapon`）。

## 常驻跃迁（Standard Warp）—— 任意 5★

| 机制 | 数值 |
|---|---|
| 5★ 硬保底 | 第 90 抽 |
| 50/50 | **无**（出货即为池内任意 5★）|
| GGanalysis | `common_5star` |
| 1 个 5★ 期望 | **≈ 62.30 抽** |

`is_guaranteed` / `radiance_losses` 对该池无效（与角色 50/50 无关）。

## 经济参数

- 抽卡货币：星琼，**160 星琼 = 1 抽**。
- 充值：≈ **¥16/抽**（648 元档，与米哈游统一口径一致）。
- 零氪约 **60 抽/月**（社区统计，近似）。

## CLI 示例

```bash
gacha analyze --game hsr --copies 1                    # 角色活动跃迁
gacha analyze --game hsr --banner weapon --copies 1    # 光锥活动跃迁
gacha analyze --game hsr --banner standard --copies 1  # 常驻任意 5★
```
